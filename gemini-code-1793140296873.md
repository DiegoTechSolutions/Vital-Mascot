# Contexto
Actúa como un Desarrollador Android Senior experto en Kotlin, Jetpack Compose, Arquitectura MVVM y Room. Necesito desarrollar una aplicación móvil completa y robusta para una Evaluación Universitaria (Evaluación Parcial 2).

# Temática del Proyecto (Vinculación con el Medio - VcM)
La aplicación es un **Gestor de Rescate y Adopción de Mascotas**. Permite a un refugio animal registrar animales rescatados con sus fotos, datos y contacto, y mostrarlos en un catálogo filtrable para posibles adoptantes.

# Requerimientos Técnicos Estrictos a Cumplir:
1. **Jetpack Compose y Material 3:** Interfaz visual moderna, atractiva y coherente. Usa Cards, Scaffold, TopAppBar, FloatingActionButton, FilterChips, y manejo de estados de carga/vacío.
2. **Arquitectura MVVM:** Separación estricta entre Model (Entities), View (Composables), ViewModel (StateFlow) y Repository.
3. **Navegación (Navigation Compose):** Flujo completo entre 3 pantallas: Listado (Home), Detalle de la Mascota, y Formulario de Registro.
4. **Validación de Formularios en tiempo real:** Campos obligatorios con mensajes de error visuales (`isError` en OutlinedTextField) si el usuario ingresa datos inválidos. El botón de guardar debe deshabilitarse si el formulario es inválido.
5. **Base de Datos Room (SQLite):** Persistencia local para guardar las mascotas.
6. **Búsqueda y Filtros:** En la pantalla principal, una barra de búsqueda por texto y "Chips" para filtrar por especie (Perro, Gato, Otro).
7. **2 Recursos Nativos del Dispositivo:**
   - **Galería:** Uso de `ActivityResultContracts.GetContent()` para seleccionar una foto de la mascota.
   - **Fecha/Hora del Sistema:** Al guardar la mascota, registrar automáticamente la fecha actual mediante `java.util.Date`.
